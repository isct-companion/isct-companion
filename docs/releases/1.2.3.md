- School pages work like a real browser again. Confirm, alert and prompt dialogs show on desktop, iPhone, iPad and Android, so Portal sign-out asks first and TSUBAME's password change goes through. Pop-up windows open as their own windows, and a pop-up that only downloads a file closes by itself.
- An LMS PDF opened in a pop-up now shows in that pop-up instead of replacing the course page behind it. On Android, files from school pages are saved to Downloads.
- School sign-in recovers on its own after the session expires, retrying at a gentle pace and stopping only when the ID or password is wrong.
- The course page shows each lesson's materials, assignments and summary the same way on every device. Lessons with recitations are labelled correctly, for example "演習 3" next to lecture 3, instead of being numbered out of order.
- A new look across the app: five background themes in Settings that follow you to your other devices, clearer tags, buttons and empty states, loading placeholders, and smoother motion that respects Reduce Motion.
- Timetable classes that start or end partway through a period fill the periods they cover, and overlapping classes sit side by side.
- On desktop, closing the main window asks whether to quit or keep running in the Dock or tray. You can remember the choice and change it later in Settings → Appearance. Windows gets a tray icon.
- On macOS and Windows, a downloaded course file can be copied or shared from the file viewer.
- Views open faster and use less memory, because each screen reads only the data it shows.
- Choosing a course in Lectures moves only that pane, and choosing the school site already on screen reloads its start page.
- On iPhone and iPad, the whole Application logs row in Settings opens its menu.
