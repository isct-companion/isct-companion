- IsctCompanion is now open source under the GNU GPL v3 or later. App-store distribution is allowed, and modified versions must use a different name.
- Scanning the Matrix card with the camera uses a new grid detector that follows the card as it moves and fills in each cell once it has been read consistently.
- Importing a Matrix card photo now uses the same reader as the camera. Cells it cannot read confidently are left blank and marked for review instead of showing a guess.
- The iPhone and Android apps can now scan the Matrix card live with the camera, filling in the grid as you hold the card in view.
- The Android app is attached to this release as an APK. It now shows the same welcome, one-time tips and verification-code setup as the other apps, and changes weeks in the timetable by swiping.
