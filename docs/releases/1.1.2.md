- See matched exams by quarter in Lecture Desk. Use Filter to search all published exams and open a selected exam in the right pane.
- Link an exam to a course and edit its date, time and room. Only the fields you change are kept, so later official corrections still arrive; reset returns to the source and keeps the link.
- The editor shows the official value beside each changed field and lists the course's other exams when linking.
- See linked upcoming exams on Today and exam cards inside course content.
- Open Calendar courses and exams in the correct Lecture Desk quarter and selected tab.
- Keep course codes visible in narrow calendar cards and fetch missing syllabus room details after a fresh setup.
- Search by course code or bilingual keywords, clear Filter in one click, and clear it when selecting an item or switching tabs.
- Classes the exam timetable lists in the exam period (授業) appear in Calendar as class sessions and in Lecture Desk as their own group, separate from exams.
- On a given day, your own changes come first, then the exam timetable, then the weekly class pattern. A day with an exam or a class no longer reads as "No classes"; exam-period days read "Exam period".
- Right-click a class or exam in Calendar to mark it as an exam, as cancelled (休講) or as a normal class. Marks sync with your other personal changes, and a cancelled session stays greyed so you can undo it.
- Exam blocks carry an exam tag after the course code, and class cards now fill their timetable cells.
- A one-time notice explains that collected data can contain mistakes and how to correct or report them.
- Configure exam notifications independently of class reminders. Marked exams, exam-week classes and cancelled sessions follow the same reminder rules.
- On macOS, notifications use the system notification service: Allow notifications shows the real system prompt, the settings page reflects notifications switched off in System Settings, and Settings → Notifications can send a test notification. New installs default to persistent alerts.
- Submitted assignments show "Submitted" instead of their deadline on Today and in Lecture Desk; missed work shows its deadline in red.
